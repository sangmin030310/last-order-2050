# Last Order 2050 | 2050: 마지막 발주

**한정된 물자와 시간 안에서 도시의 공급망을 복구하는 1인용 2D 스토리 탐험 게임입니다.**

2050년, 폭우로 가상 도시 다온시의 공급망이 끊깁니다. 플레이어는 조달청 긴급조달 지원팀의 **조달이**와 **조달호**를 조작해 병원의 긴급 요청을 조사하고, 필요한 부품과 원자재를 확보합니다. 마지막에는 정수시설과 통신시설 중 어디에 물자를 먼저 보낼지 결정합니다.

- **개발 배경** · 2026 조달청 AI 게임·콘텐츠 공모전 AI 게임 부문
- **팀 구성** · 2인
- **개발 환경** · Godot 4.7.2, GDScript
- **개발 상태** · 개발 중
- **현재 구현 범위** · 오프닝, 프롤로그, 1~3장, 최종장, 엔딩 5종

## 기획 의도

재난 상황에서 공공조달을 지원할 때 따져야 할 조건을 게임의 선택으로 풀어냈습니다. 병원에 필요한 부품은 규격이 맞아도 안전 검사가 끝나지 않았거나 제때 도착하지 못하면 사용할 수 없습니다. 정수시설과 통신시설이 서로 다른 업체와 계약했더라도 핵심 부품 공급처가 같다면 두 시설이 동시에 영향을 받을 수 있습니다.

플레이어가 직접 부품과 계약기록을 비교하고, 그 판단이 시설의 복구 경과와 결과 보고서에 남도록 설계했습니다. 다온시와 게임 속 「나라장터 2050」 단말기는 가상이며, 유휴 물품 이관과 긴급계약, 비축 원자재 공급 절차는 게임에 맞춰 단순화했습니다.

## 구현한 기능

| 구간 | 플레이어가 하는 일 |
| --- | --- |
| **프롤로그 · 병원의 긴급 호출** | 오프닝 후 출동 캐릭터를 선택하고, 제한 시간 5초 안에 병원 무전 신호를 맞춥니다. |
| **1장 · 병원 긴급조달** | 두 캐릭터를 바꿔 조작하며 발판과 문을 통과합니다. 부품의 규격·안전성·납기를 비교해 공공창고 유휴 부품 이관과 국내 대체품 공급 중 하나를 선택합니다. |
| **2장 · 공급망 위험 조사** | 두 시설의 계약기록을 대조해 공통 핵심 공급처를 찾아냅니다. 공급 중단 위험을 시설에 미리 알릴지 결정합니다. |
| **3장 · 비축 원자재 공급** | 제조사의 신청 자격과 재고, 공급 조건을 확인합니다. 조달호는 분전반을 조작하고, 조달이는 구리 두 묶음을 운반해 검사합니다. |
| **최종장 · 배차와 복구** | 기존 모듈을 먼저 보낼 시설과 비상전력 지원 여부를 결정합니다. 공급계획을 확정하기 전 예상 중단 여부를 확인하고, 확정 후에는 시설별 복구 경과와 결과 보고서를 봅니다. |

탐험 화면에는 현재 목표와 조사할 위치를 표시합니다. 일시정지 메뉴에서 조작법, 현장 무전 기록, 조달정책 설명을 다시 읽을 수 있습니다.

## 배차 선택이 엔딩으로 이어지는 방식

기존 모듈은 **4시간**, 후속 모듈은 **12시간**에 도착합니다. 정수시설은 **6시간**, 통신시설은 **9시간**까지 버팁니다. 앞 장에서 재난망 기록을 발견했다면, 기존 모듈을 정수시설에 먼저 보내고 비상전력 지원을 예약할 수 있습니다. 이 경우 통신시설이 **14시간**까지 버텨 후속 모듈을 받을 수 있습니다.

[`story.gd`](./story.gd)는 사전 위험 통보와 재난망 기록 등 앞선 장의 선택을 보관합니다. [`recovery.gd`](./recovery.gd)는 시설별 도착 시간과 가동 한계를 비교해 **엔딩 5종과 시설별 결과 보고서**를 구성합니다. 엔딩 화면에서 최종 배차를 다시 선택해 다른 결과를 비교할 수 있습니다.

## 검증과 보완 과제

Godot 4.7.2에서 **헤드리스 자동 테스트 15개를 실행해 모두 통과**했습니다. 병원 협동 퍼즐, 비축창고 승인·검수, 최종 배차와 엔딩 분기, UI 배치를 점검했습니다.

- **중반부 플레이 흐름** · 기록실과 제조사 구간은 이동한 뒤 문서나 대화창을 확인하는 비중이 큽니다. 조사한 단서가 다음 탐색 장소나 공급 경로 선택으로 이어지도록 보완할 수 있습니다.
- **사운드와 이동 연출** · 오프닝에 음향을 적용했습니다. 본편에서는 시설별 환경음, 발걸음, 걷기 애니메이션이 보완 과제입니다.
- **진행 저장과 배포** · 화면 설정은 저장되며, 스토리 진행은 실행 중 메모리에 보관됩니다. 장별 체크포인트와 Windows 또는 웹 실행 빌드가 남아 있습니다.
