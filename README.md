# Last Order 2050 | 2050: 마지막 발주

**한정된 물자와 시간 안에서 도시의 공급망을 복구하는 1인용 2D 스토리 탐험 게임입니다.**

폭우로 공급망이 끊긴 2050년의 가상 도시 다온시. 플레이어는 조달청 긴급조달 지원팀의 조달이와 조달호를 번갈아 조작합니다. 병원의 긴급 요청을 조사하고, 필요한 부품과 원자재를 확보한 뒤, 정수시설과 통신시설 중 어디에 물자를 먼저 보낼지 결정합니다.

- **개발 배경** · 2026 조달청 AI 게임·콘텐츠 공모전 AI 게임 부문
- **개발 환경** · Godot 4.7.2, GDScript
- **구현 범위** · 오프닝, 프롤로그, 1~3장, 최종장, 엔딩 5종

## 기획 의도

재난 상황에서 조달청이 물자 공급을 지원할 때 어떤 조건을 따져야 하는지 게임 속 선택으로 풀어냈습니다. 병원에 필요한 부품은 규격이 맞더라도 안전 검사가 끝나지 않았거나 납기가 늦으면 쓸 수 없습니다. 두 시설이 서로 다른 업체와 계약했더라도 핵심 부품을 같은 공급처에 의존하면 함께 영향을 받을 수 있습니다. 플레이어가 이런 문제를 발견하고 내린 판단이 최종 복구 결과와 보고서에 남도록 구성했습니다.

다온시와 사건, 게임 속 「나라장터 2050」 단말기는 가상의 설정입니다. 공공기관 간 유휴 물품 이관, 대체품 긴급계약 검토, 비축 원자재 공급 절차는 게임 진행에 맞춰 단순화했습니다.

## 구현한 기능

| 구간 | 구현 내용 |
| --- | --- |
| **오프닝·프롤로그** | 오프닝 영상과 출동 캐릭터 선택 화면을 구현했습니다. 구호본부에서 병원 무전 신호를 맞추는 미니게임은 5초 제한과 재시도를 지원합니다. |
| **1장 · 병원 긴급조달** | 두 캐릭터를 바꿔 조작하며 발판과 문을 통과합니다. 부품의 규격·안전성·납기를 비교해 공공창고 유휴 부품 이관 또는 검증된 국내 대체품 공급 경로를 선택합니다. |
| **2장 · 공급망 위험 조사** | 정수시설과 통신시설의 계약기록을 대조해 공통 핵심 공급처를 찾아냅니다. 두 시설에 위험을 미리 알릴지 결정하며, 이 선택은 엔딩과 보고서에 반영됩니다. |
| **3장 · 비축 원자재 공급** | 제조사의 신청 자격, 재고와 공급 조건, 승인 결과를 확인합니다. 조달호가 분전반을 조작하고 조달이가 구리 두 묶음을 운반·검사합니다. 재난망 기록을 찾으면 최종장에서 비상전력 지원을 검토할 수 있습니다. |
| **최종장 · 배차와 복구** | 기존 모듈의 우선 배차와 비상전력 지원 여부를 결정합니다. 확정 전에는 시설별 도착 시간과 예상 중단 여부를, 확정 후에는 도시 복구 경과와 긴급조달 결과 보고서를 확인할 수 있습니다. |

탐험 화면에는 현재 목표와 상호작용 지점을 표시합니다. 일시정지 메뉴에서 조작법, 현장 무전 기록, 조달정책 설명을 다시 볼 수 있습니다. 창 표시 방식과 글자 크기 설정은 다음 실행에도 유지됩니다.

## 선택이 결과로 이어지는 방식

최종장에서 기존 모듈은 4시간, 후속 모듈은 12시간에 도착합니다. 정수시설의 가동 한계는 6시간, 통신시설은 9시간입니다. 정수시설에 먼저 배차하고 비상전력 지원을 예약하면 통신시설의 가동 한계가 14시간으로 늘어나 두 시설을 모두 유지할 수 있습니다.

`Story` 자동 로드 노드에 병원 공급 경로, 위험 통보 여부, 재난망 기록 등 장면 간 진행 상태를 보관합니다. 최종 배차 로직은 시설별 도착 시간과 가동 한계를 비교하고 사전 통보 여부를 반영해 **엔딩 5종**과 **시설별 결과 보고서**를 구성합니다. 엔딩 화면에서는 최종 배차를 다시 선택해 결과를 비교할 수 있습니다.

## 실행 방법

1. 소스 파일을 내려받습니다.
2. Godot 4.7.2 프로젝트 관리자에서 `project.godot`을 가져옵니다.
3. 프로젝트를 열고 **F5**를 누른 뒤 **게임 시작**을 선택합니다.

| 조작 | 기능 |
| --- | --- |
| WASD / 방향키 | 이동 |
| E | 조사, 장치 조작, 물자 운반·인계 |
| Tab | 병원과 비축창고에서 조작 캐릭터 전환 |
| Esc | 오프닝 건너뛰기 또는 일시정지 |

## 검증 및 개선점

Godot 4.7.2에서 **헤드리스 자동 점검 15개를 실행해 모두 통과**했습니다. 병원 발판과 문, 비축창고 승인·검수, 최종 배차, 엔딩 5종, 메뉴와 UI 배치를 점검했습니다. 화면에서 처음부터 끝까지 직접 플레이하며 조작감과 진행 속도를 확인하는 검증은 남아 있습니다.

| 개선 항목 | 현재 상태와 보완 방향 |
| --- | --- |
| **중반부 플레이 흐름** | 기록실과 제조사 구간에는 이동 후 문서나 대화창을 확인하는 장면이 많습니다. 기록에서 찾은 단서로 다음 조사 장소를 판단하게 하면 탐색과 추리를 더 자연스럽게 연결할 수 있습니다. |
| **공급 전략의 선택 폭** | 병원에서는 두 가지 공급 경로를 선택할 수 있습니다. 2장에서는 검증된 대체 공급처를 골라야 진행됩니다. 납기와 안전성의 조건이 다른 유효한 경로를 추가하면 중반부 선택도 이후 결과에 영향을 줄 수 있습니다. |
| **사운드와 캐릭터 연출** | 오프닝 영상에 소리가 포함돼 있으며, 본편에는 별도 배경음악과 효과음이 연결돼 있지 않습니다. 시설별 환경음과 발걸음 소리, 방향별 걷기 프레임을 추가하는 것이 보완 과제입니다. |
| **진행 저장과 배포** | 화면 설정은 파일에 저장됩니다. 스토리 진행은 실행 중 메모리에 보관되며, 현재 버전은 Godot 프로젝트 소스 형태입니다. 장별 체크포인트와 Windows 또는 웹 실행 빌드가 다음 작업입니다. |
